# FriendGroupList

A community-created list ranking the hardest Geometry Dash levels made and verified by members of the FriendGroup.

🌐 Live Website:
https://useryipee.github.io/FriendGroupList

## Features
- Ranked levels
- Player leaderboard
- Statistics
- Responsive design

## What is FGL?
FriendGroupList (FGL) is inspired by Pointercrate but focuses exclusively on levels created within our friend group.
